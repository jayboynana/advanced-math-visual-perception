# DynaMath provenance

Official dataset: https://huggingface.co/datasets/DynaMath/DynaMath_Sample

Project: https://dynamath.github.io/

The official dataset card declares Apache-2.0. This benchmark uses the 501 images from the first sample variant at revision `bc7fcd1ae58caa445d61f6dc0c241b0bb8a7f4c6`, acquired on 2026-11-13. The local parquet file corresponds to `data/sample1-00000-of-00001.parquet` with SHA-256 `7cc1e3e75ff4b6087795db7c3996f70123ed8b4059e99ee43aa609436456ff26`. Each file preserves the embedded image bytes. No original question or answer is included in the annotation or evaluation exports.

`catalog.json` records source IDs, original paths, dimensions and image hashes. Visual types in the benchmark are assigned from the image content.
