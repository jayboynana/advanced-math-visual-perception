# VisioMath provenance

The official [VisioMath repository](https://github.com/Nefefilibata/VisioMath/tree/4a912153e110001da261917902e1d3cc163b7c6a) accompanies the [ICLR 2026 paper](https://openreview.net/pdf?id=31pzK2VSQQ). Its README directs users to unpack the image archive and requests citation for research use. No license file or repository license declaration was present at this revision.

The JSON has 1,800 question records and 8,070 unique image references. The published ZIP contains 6,389 corresponding images. The catalog includes those available originals and omits the 1,681 references missing from the ZIP. Surrounding whitespace was stripped from JSON image names for matching only. Each image file is the exact byte stream extracted from the archive, with its original filename. The catalog identifies the upstream question and whether the image is a stem or an answer-option diagram. `benchmark` is our name for the upstream release, which provides no separate split fields.
